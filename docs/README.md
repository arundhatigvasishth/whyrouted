# docs

| Path | What it is | Lifespan |
|---|---|---|
| [`prd.md`](prd.md) | Product spec (PRD v3) — vision, scope, milestones, tech stack | permanent |
| [`architecture/`](architecture/) | Design record — one architecture review per milestone, signed off at each boundary | permanent |
| [`decisions.md`](decisions.md) | Load-bearing technical decisions and their rationale | permanent |
| [`milestones/`](milestones/) | Per-milestone planning — task splits, idea/scoping docs, interface contracts | scaffolding — deleted when the project wraps |

The working agreement (commits, branches, PRs, review) is in
[`../CONTRIBUTING.md`](../CONTRIBUTING.md).

When the project is done, `docs/milestones/` gets removed wholesale. Everything
else stays.
